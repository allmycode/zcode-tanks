# Танки — Battle Tanks (tribute to Battle City, NES)

Классическая аркада с видом сверху по мотивам Battle City / Battle Tanks (NES).
Один файл — просто откройте `index.html` в браузере (Chrome / Edge / Firefox).

## Управление

| Клавиша | Действие |
|---|---|
| Стрелки / WASD | движение |
| Space (или Z) | выстрел |
| Enter | старт / подтверждение |
| ← / → на титуле | выбор этапа |
| P или Esc | пауза |
| M | звук вкл/выкл |

## Правила

- Защищайте базу — орла внизу. 20 врагов на этап, на поле максимум 4–5.
- Кирпич разрушается, сталь — только прокачанной пушкой (3 звезды).
- Листва скрывает танки, лёд — скольжение, воду танки не проходят (пули летят).
- Красные мигающие танки оставляют бонус: ⭐ звезда (апгрейд), ⛑ шлем (щит),
  💣 граната (взрыв всех), ⏱ таймер (заморозка), ⛏ лопата (стальная броня базы),
  🚩 танк (+1 жизнь).
- Очки: 100/200/300/400 за тип танка, 500 за бонус, доп. жизнь каждые 20000.
- HI-SCORE сохраняется локально.

## Файлы

- `index.html` — страница с канвасом
- `game.js` — вся игра (движок, спрайты, звук на Web Audio)
